# MailKit Agent 部署指南

版本：0.2.0（win-x64）｜ 更新日期：2026-08-20

MailKit Agent 是一个基于 MCP（Model Context Protocol）的邮件代理服务器：AI 助手通过它安全地读取 IMAP/POP3 邮箱并投递经人工确认的邮件。密码只保存在 Windows 凭据管理器，绝不进入命令行、日志或模型上下文。

## 一、包内容

`mailkit-agent-0.2.0-win-x64.zip`（约 6.2 MB，解压后即用）：

```text
mailkit-agent/
  .codex-plugin/plugin.json    Codex 插件宿主的清单文件
  .mcp.json                    stdio 传输的 MCP 服务器声明
  skills/mailbox/SKILL.md      邮箱技能使用规范（给 AI 宿主读取）
  server/                      发布产物（自包含于 .NET 8 目标框架）
    mailkit-agent.dll          MCP 服务器主程序（dotnet 承载）
    mailkit-agent.exe          Windows apphost（可直接执行凭据 CLI）
    MailKit.Agent.Core.dll     协议无关核心
    MailKit.Agent.Auth.dll     Windows 凭据管理器实现
    MailKit.Agent.Mail.dll     MailKit/MimeKit 适配层（含发送审批硬门控）
    MailKit.dll / MimeKit.dll  上游协议库
    其余依赖项与符号文件
```

## 二、前置要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 及以上（首发平台）。非 Windows 上构建仍可，但凭据操作返回 `credential.platform_unsupported` |
| 运行时 | .NET SDK 或运行时 8.0 及以上（`dotnet --version` 可验证） |
| 桌面环境 | 发送审批使用 `confirm_dialog` 模式时需要交互式桌面（弹原生确认框）；无桌面环境请用 `drafts` 模式（见使用指南） |
| 网络 | 能访问目标邮件服务器（仅 TLS：implicit_tls 993/995/465 或 start_tls 587） |

## 三、安装到 Agent 工具

### 方式 A：通用 MCP 宿主（Claude Code、Cursor、其他支持 stdio MCP 的工具）

1. 解压 zip 到任意固定目录，例如 `C:\Tools\mailkit-agent\`。
2. 在宿主的 MCP 服务器配置中加入（以 Claude Code 项目级 `.mcp.json` 为例，其他工具字段名基本一致）：

```json
{
  "mcpServers": {
    "mailkit-agent": {
      "command": "dotnet",
      "args": ["C:/Tools/mailkit-agent/server/mailkit-agent.dll"],
      "cwd": "C:/Tools/mailkit-agent"
    }
  }
}
```

> 说明：包内自带的 `.mcp.json` 使用相对路径 `server/mailkit-agent.dll`，适用于以插件根为工作目录的宿主；通用宿主建议写 DLL 绝对路径。`cwd` 指向插件根即可。

3. 重启宿主或重载 MCP 连接，工具列表应出现 17 个 `*_list`/`message_*`/`send_*` 等工具。

### 方式 B：Codex 插件宿主

将整个 `mailkit-agent/` 目录放入宿主的插件目录（保留 `.codex-plugin/plugin.json` 结构），宿主会按清单自动注册 MCP 服务器与技能。

## 四、初始化（每台机器一次）

### 1. 写入邮箱密码（仅本地终端操作，勿在聊天中输入）

```powershell
cd C:\Tools\mailkit-agent
.\server\mailkit-agent.exe account credential set --account personal
# 按提示输入密码（不回显）；写入 Windows 凭据管理器目标
# MailKit.Agent/account/personal/password
```

其余凭据命令：

```powershell
.\server\mailkit-agent.exe account credential status --account personal   # 只报是否已配置
.\server\mailkit-agent.exe account credential delete --account personal   # 删除该账户凭据
```

### 2. 配置账户（非秘密 JSON）

让宿主里的 AI 调用 `account_profile_put`，或直接手写数据文件（默认路径 `%LOCALAPPDATA%\MailKit.Agent\accounts\personal.json`）：

```json
{
  "id": "personal",
  "display_name": "个人邮箱",
  "username": "you@example.com",
  "authentication": "password",
  "send_mode": "confirm_dialog",
  "imap": { "host": "imap.example.com", "port": 993, "tls": "implicit_tls" },
  "pop3": null,
  "smtp": { "host": "smtp.example.com", "port": 465, "tls": "implicit_tls" }
}
```

- `tls` 仅接受 `implicit_tls` / `start_tls`，`plain` 会被拒绝。
- `send_mode` 可选 `confirm_dialog`（默认，桌面弹窗确认后发送）或 `drafts`（保存到草稿箱，由你手动发送），详见使用指南。
- 至少配置 imap/pop3/smtp 之一；`authentication` 当前仅支持 `password`。

## 五、部署验证

1. 连接测试：让 AI 调用 `account_connection_test`（三个协议各返回 connected/tls/authenticated）。
2. 健康检查：调用 `diagnostics_health` 应返回服务器标识与 stdio 传输确认。
3. 发送门控自检（可选）：`send_prepare` 一封测试邮件 → `send_commit` 时桌面应弹出确认对话框（`confirm_dialog` 模式）或草稿箱出现新草稿（`drafts` 模式）。

## 六、数据目录

| 内容 | 默认位置 |
|---|---|
| 账户配置 | `%LOCALAPPDATA%\MailKit.Agent\accounts\<id>.json` |
| 附件下载根 | `%LOCALAPPDATA%\MailKit.Agent\downloads` |
| 发送幂等账本 | `%LOCALAPPDATA%\MailKit.Agent\send-ledger\<id>\<key-hash>.json` |

环境变量覆盖：`PLUGIN_DATA`、`MAILKIT_AGENT_DATA_DIR`（数据根）、`MAILKIT_AGENT_DOWNLOAD_ROOT`（下载根）。密码永不出现在以上任何文件中。

## 七、卸载

删除插件目录、数据目录，并在凭据管理器中删除 `MailKit.Agent/account/<id>/password`（用 CLI delete 或 Windows 凭据管理器界面）。
